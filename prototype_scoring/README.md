# Модуль приоритизации объектов электросети

Интерактивный прототип модуля приоритизации объектов для формирования ремонтной программы по техническому состоянию.

## Технологии

- React 19
- Ant Design 6
- Vite 8

## Запуск

```bash
cd prototype_scoring
npm install
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173

## Сборка для production

```bash
npm run build
```

## Функционал прототипа

### 1. Скоринговая модель

Расчёт итогового балла приоритета объекта по формуле:

**P = wD × D + wW × W + wC × C + wT × T**

Где:
- **D (40%)** — Дефектная нагрузка (взвешенная сумма открытых дефектов)
- **W (25%)** — Износ (отношение фактического возраста к нормативному сроку)
- **C (20%)** — Последствия отказа (класс напряжения + категория надёжности + соцобъекты)
- **T (15%)** — Результаты испытаний (отклонения параметров от нормы)

### 2. Категории приоритета

| Категория | Диапазон P | Цвет |
|-----------|------------|------|
| Критичный | ≥ 7.5 | 🔴 Красный |
| Высокий | 5.0 – 7.4 | 🟠 Оранжевый |
| Средний | 2.5 – 4.9 | 🟡 Жёлтый |
| Низкий | < 2.5 | 🟢 Зелёный |

**Блокирующий дефект**: при наличии дефекта с `isBlocking=true` объект автоматически получает категорию "Критичный".

### 3. Рекомендация вида ремонта

Система рекомендует вид ремонта по правилам:

| Условие | Рекомендация |
|---------|--------------|
| Дефект ст. 3 И износ ≥ 70% | Капитальный ремонт (КР) |
| Дефект ст. 3 И износ < 70% | Текущий ремонт (ТР) |
| Дефект ст. 2 И износ ≥ 80% | Средний ремонт (СР) |
| Только дефекты ст. 1 | Техническое обслуживание (ТО) |

### 4. Интерфейс

#### Экран рекомендаций
- **Панель фильтров**: год планирования, тип актива, класс напряжения, категория приоритета
- **Строка статистики**: количество объектов в каждой категории
- **Таблица объектов**: сортировка по убыванию балла, индикаторы износа и дефектов

#### Боковая панель детализации (Drawer)
- Итоговый балл и категория приоритета
- Декомпозиция балла по компонентам (D, W, C, T)
- Список дефектов с указанием степени
- Рекомендация вида ремонта с обоснованием
- Кнопки действий: "В план", "Отложить"

### 5. Демо-данные

В прототипе включено 8 объектов различных типов:
- ВЛ (воздушные линии): 0.4 кВ, 10 кВ, 35 кВ
- ТП (трансформаторные подстанции): 0.4 кВ
- КЛ (кабельные линии): 6 кВ
- ПС (подстанции): 110 кВ
- КТП (комплектные трансформаторные подстанции): 10 кВ

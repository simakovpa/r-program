# r-program
Прототип формирования ЛСР при планировании ремонтной программы, сгруппированный по мероприятиям, а не типам затрат.

# Принятые решения
- При выборе одного и того же мероприятия несколько раз в ЛСР они не объединяются, т.к. хоть и мероприятие одинаковое, но внутри может быть выбран разный состав ТМЦ
